# Antigravity Auto-Run Extension

Tự động click Run/Accept/Allow/Continue trong Antigravity IDE thông qua CDP.

## Cách sử dụng
- Sau khi cài đặt, Extension tự động khởi chạy và hiển thị trạng thái `⚡ Auto-Run: ON` trên thanh StatusBar phía dưới bên phải.
- Click chuột vào nút trên StatusBar để Bật/Tắt nhanh.
